# Сlient for messenger


Клиентское приложение для мессенджера,предоставляет графический интерфейс для подключения к серверу и обмена сообщениями между пользователями в реальном времени.

Исходный код серверной части приложения доступен в репозитории: https://github.com/h3rodesu/Messenger_Server

## Технологический стек
* **Язык программирования:** C++20
* **Графическая библиотека:** Dear ImGui: https://github.com/ocornut/imgui?ysclid=mud3ry2vzt483495607
* **Система сборки:** CMake (версия 3.15)
* **Сетевое взаимодействие:** WinSock API (Winsock2), протокол TCP

## Структура проекта
**Примечание:** Все необходимые файлы исходного кода библиотеки Dear ImGui включены напрямую в репозиторий проекта для упрощения сборки и независимости от внешних зависимостей.

* **`client.cpp`** - Точка входа в программу. Содержит главный цикл приложения, инициализацию графического окна, логику подключения к серверу и обработку пользовательского ввода.
* **`Receive.h` / `Receive.cpp`** - Модуль обработки входящих сетевых соединений и приема данных от сервера.
* **`Learning`**  - асинхронная фоновая функция (работает в std::jthread). Отвечает за непрерывный прием сетевых данных от сервера, обработку ошибок, парсинг системных команд и потокобезопасное обновление состояния приложения.
### Графический интерфейс
* **`imgui.h` / `imgui.cpp`** - Базовые файлы библиотеки Dear ImGui, отвечающие за рендеринг элементов интерфейса.
* **`imconfig.h`** - Файл конфигурации библиотеки ImGui.
* **`imgui_demo.cpp`** - Встроенный справочный файл с примерами виджетов.
* **`imgui.ini`** - Конфигурационный файл сохранения геометрии и положения окон между запусками.

**Настройки сборки:**
* CMakeLists.txt - сценарий сборки CMake, описывающий правила компиляции и линковки проекта.

## Сборка и запуск

### Требования к окружению
* Компилятор с поддержкой стандарта C++20
* CMake версии 3.15 или выше

### Сборка через консоль (CMake)
Выполните следующие команды в терминале из корневой папки проекта:

```bash
mkdir build
cd build
cmake ..
cmake --build . --config Release
```

### Запуск приложения
После успешной сборки исполняемый файл появится в папке build/Release. Запустите его командой:

```bash
.\Release\client.exe
```
